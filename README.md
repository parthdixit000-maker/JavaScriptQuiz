JavaScript Quiz Application

About:
This project is a simple quiz application developed using JavaScript and HTML. It asks users five GK questions, checks their answers, and calculates their final score.

Quiz Questions:

1. Which is the largest ocean in the world?
   - Answer: Pacific Ocean

2. How many continents are there in the world?
   - Answer: 7

3. Which gas do plants absorb from the atmosphere?  
   - Answer: Carbon Dioxide

4. Who invented the telephone?
   - Answer: Alexander Graham Bell

5. Which is the smallest prime number?
   - Answer: 2
Features

- Contains five general knowledge questions.
- Takes user input using the prompt() function.
- Checks answers automatically.
- Converts answers into lowercase.
- Removes extra spaces using trim().
- Displays correct and incorrect messages.
- Shows the final score at the end.

Languages used

- JavaScript
- HTML

How to Run:

1. Create a file named "script.js".
2. Copy the JavaScript quiz code into the file.
3. Open an HTML file in a web browser and link the JavaScript file.
4. Answer the questions displayed in the prompt boxes.
5. View your final score after completing the quiz.

Expected Output

- Displays "Correct!" for correct answers.
- Displays the correct answer for incorrect responses.
- Displays the final score out of 5.
